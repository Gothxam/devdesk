# DevDesk

DevDesk is a modern workspace & developer desktop environment built for high performance and extensibility.

## 🎯 Three Sources of Truth

DevDesk maintains a strict separation of concerns to avoid documentation bloat:

* 📄 **`docs/`** — **Specifications**: Functional specifications, system architecture, API definitions, and ADRs (what the system should do).
* 🧠 **`knowledge/`** — **Research & Notes**: Spikes, performance benchmarks, technology deep-dives (what we've learned).
* 🤖 **`.ai/`** — **AI Agent Context**: Agent instructions, prompts, decision logs, and rules (how AI agents should operate).

## 📁 Repository Structure

```text
devdesk/
├── apps/         # Applications
├── packages/     # Shared core libraries & packages
├── widgets/      # Modular UI widgets
├── plugins/      # Plugin system & extensions
├── themes/       # UI themes & design systems
├── docs/         # System specifications
├── knowledge/    # Technical research & learnings
├── .ai/          # AI agent context & instructions
├── assets/       # Static media & design assets
├── scripts/      # Automation & build scripts
├── examples/     # Demo applications & usage samples
├── tools/        # Internal developer utilities
└── tests/        # Test suites & benchmarks
```
