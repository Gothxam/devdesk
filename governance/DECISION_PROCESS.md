# Decision Process & Lifecycle

## 🔁 Feature Lifecycle

```text
Idea ➔ Discussion ➔ ADR (docs/adr/) ➔ Implementation ➔ Review ➔ Merge
```

### Steps:
1. **Idea**: Captured in `planning/ideas.md` or via a GitHub Issue (`FEATURE_REQUEST.md`).
2. **Discussion**: Vetted in issue/planning notes.
3. **ADR Creation**: For any architectural change, write `docs/adr/ADR-XXXX-title.md`.
4. **Implementation**: Developed on a dedicated feature branch.
5. **Review**: PR submitted with standard template (`.github/PULL_REQUEST_TEMPLATE.md`).
6. **Merge**: Merged to `main` upon approval.
